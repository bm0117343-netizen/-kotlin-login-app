# مشروع كوتلين — Login App

مشروع أندرويد بلغة كوتلين (Jetpack Compose) فيه 4 صفحات بالترتيب المطلوب.

## الصفحات

1. **Splash Screen** — بتظهر ثانيتين وبعدها بتمشي لصفحة الدخول، ولو الزول مسجل دخولو قبل كده بتمشي طوالي لصفحة الاسم.
2. **Login** — إيميل وكلمة مرور، وبتتحقق من البيانات المحفوظة في الجهاز.
3. **Register** — إيميل وكلمة المرور وتأكيدها بس، ما فيها خانة اسم، وبتحفظ البيانات في الجهاز.
4. **Home** — صفحة براها، فيها الاسم الثابت في نص الشاشة بالضبط، ومعاها زر Logout. أي حساب يتعمل بيدخل لنفس صفحة الاسم دي.

## حفظ البيانات

البيانات بتتحفظ في الجهاز نفسه عن طريق `SharedPreferences`
(الملف: `data/UserPreferences.kt`) — ما محتاجة إنترنت ولا سيرفر.
لو دخلت بإيميل أو كلمة مرور غلط، بتظهر رسالة خطأ وما بتدخل.

الاسم البظهر في صفحة Home ثابت وما بيتعدل من التطبيق،
وهو مكتوب في الكود نفسه في `UserPreferences.kt`،
وأي حساب يتعمل بيدخل لنفس الاسم:

## كيف تشغلو في Android Studio — خطوة خطوة

1. فك ضغط الملف، وحتتلقى مجلد اسمو `kotlin-login-project`.
2. افتح Android Studio.
3. اختار `Open`، واختار مجلد `kotlin-login-project`، واضغط `OK`.
4. استنى شوية لحدي ما Gradle يخلص التحميل والمزامنة (Sync) — ما تضغط أي حاجة لحدي ما تخلص.
5. لو طلب منك تنزيل SDK أو تحديث، وافق وخليهو يكمل.
6. شغّل محاكي (Emulator) من Device Manager، أو وصّل تلفونك وفعّل فيه USB Debugging.
7. اضغط زر التشغيل الأخضر ▶️ فوق، واستنى التطبيق يتبني ويفتح.
8. جرّب: اعمل Register أول مرة بإيميل وكلمة مرور 6 أحرف أو أكتر،
   حتدخل طوالي لصفحة الاسم. بعدها اعمل Logout وجرّب Login بنفس البيانات.

## ملفات الكود المهمة

- `MainActivity.kt` — التنقل بين الصفحات (Navigation).
- `ui/screens/SplashScreen.kt`
- `ui/screens/LoginScreen.kt`
- `ui/screens/RegisterScreen.kt`
- `ui/screens/HomeScreen.kt` — صفحة الاسم في نص الشاشة.
- `data/UserPreferences.kt` — حفظ بيانات التسجيل والدخول في الجهاز.
- `ui/theme/` — الألوان والخطوط.

## متطلبات التشغيل

- Android Studio Ladybug أو أحدث.
- compileSdk 34 / minSdk 24.
- Kotlin 2.0.20 — Gradle 8.7.
